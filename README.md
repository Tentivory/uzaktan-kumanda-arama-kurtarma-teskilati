# Uzaktan Kumanda Arama Kurtarma Teşkilatı

**Kanun Hükmünde Kararname No:** 42/YASTIK  
**Kuruluş amacı:** Kanepe yastığının altına giren uzaktan kumandanın uluslararası hukuktaki statüsünü belirlemek ve mümkünse bulmak.

Bu yazılım şaka değildir. Şaka olsaydı pil çekmecesinde dururdu.  
Bu yazılım çalışır. Çalışmasaydı zaten kumanda gibi kaybolurdu.

## Resmi görev tanımı

1. Yastığı kaldır.
2. Kumandayı görme.
3. Yastığı suçla.
4. Rapor yaz.
5. Televizyonu açık bırakıp sesle kanal değiştirmeyi dene.
6. Aya kalkmamayı milli politika haline getir.

## Kurulum

```bash
python3 arama_kurtarma.py
```

Kayıp nesneyi özelleştirmek isterseniz:

```bash
python3 arama_kurtarma.py "o küçük siyah şey"
```

## Bilimsel dayanak

- Kanepe yastığı, fizik kurallarının tatil yaptığı yerdir.
- Kumanda her zaman "az önce buradaydı" konumundadır.
- Piller asla evde bitmez; ev, pilleri bitirir.
- Arama süresi, dizi jeneriğinin uzunluğuyla doğru orantılıdır.

## Sık sorulan sorular

**Kumanda bulundu mu?**  
Bazen. Çoğunlukla hayır. İstatistiki olarak elinizdeydi.

**Neden Python?**  
Çünkü Java kumandayı üç kez ters takardı.

**Patates var mı?**  
Yok. Yastık var. Kumanda var. Biraz da milli gurur var.

## Sorumluluk reddi

Teşkilat; kayıp kumanda, kayıp pil, kayıp dizi bölümü ve kayıp irade nedeniyle sorumlu tutulamaz.
